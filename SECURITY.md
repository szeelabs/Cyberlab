# Security Policy

## Reporting a vulnerability
Please **do not open a public issue**. Use GitHub's private
[security advisory](../../security/advisories/new) form for this repository. We aim to
acknowledge reports within 7 days.

## Scope
The control-plane API, manifest parsing/policy engine, authentication, and (in later
phases) environment isolation, terminal gateway and storage.

## Acceptable use
CyberLab is for education, defense and authorized testing only. Using CyberLab
environments against systems without the owner's permission is prohibited. Operators
should keep audit logs and act on abuse reports.

## Supported versions
Pre-1.0: only the latest `main` receives fixes.
